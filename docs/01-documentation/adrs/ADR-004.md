# ADR-004: Go userspace orchestration — BLAKE3 Merkle + pwrite splicing

## Status
Accepted

## Context

The userspace daemon must consume ring-buffer telemetry, verify pre-image
integrity, and restore affected file regions surgically without full-file
rewrites.

Constraints:
- Asynchronous, lock-free consumption of the eBPF ring buffer via
  zero-copy shared memory.
- Pre-image integrity verified with BLAKE3 Merkle commitments.
- Restoration via targeted `pwrite64` on the underlying file descriptor
  at the original extent offset (surgical splicing).
- Latency budget: ~82 μs eBPF interception, ~210 μs descriptor
  collection, ~126 μs extent restoration (~418 μs total containment).

Options Considered
1. **Go daemon polling the ring buffer via libbpf ringbuf API** — simple
   but introduces syscall per read; not zero-copy enough.
2. **Go daemon mmap of pinned ring buffer pages** — true zero-copy shared
   memory; chosen.
3. **Full-file restore from backup** — simple but slow; violates
   surgical-splicing requirement and latency budget.
4. **pwrite64 of pre-image bytes at original offset** — surgical,
   extent-level restoration; chosen over full-file rewrite.

## Decision

Build an asynchronous Go daemon that mmaps the pinned per-PID ring buffer,
verifies each extent with a BLAKE3 Merkle commitment, and on confirmed
anomaly issues `pwrite64` of the captured pre-image bytes at the original
file offset to splice the region back to its pre-infection state.

## Consequences

### Positive
- Zero-copy ring buffer consumption.
- Extent-level (surgical) restoration, not full-file rewrite.
- BLAKE3 Merkle commitments detect tampered or corrupted pre-images.

### Negative
- Requires the daemon to hold the file descriptor open and have write
  permission (root/CAP_DAC_OVERRIDE typical).
- `pwrite64` races with concurrent writers must be coordinated with the
  eBPF allowlist and process termination.

## Revisit When

Concurrent-writer races during restoration cause journal desync; add a
per-inode restoration lock or sequence the restore after process-tree
termination.

# ADR-003: Rolling byte-entropy + magic-byte delta anomaly classification

## Status
Accepted

## Context

Each intercepted write must be classified as suspect or benign before the
pre-image is diverted, using only data available at the VFS boundary.
Classification must complete in sub-microsecond time.

Constraints:
- Rolling Shannon byte-entropy over a 64-byte window.
- Entropy threshold of 7.5 bits/byte marks a write as suspect.
- Structural magic-byte delta: compare observed file header against
  expected magic for the inferred file type; max 4 mismatches allowed.
- Classification runs inside eBPF (no heap, bounded loops, verifier-safe).

Options Considered
1. **Full Shannon entropy over entire write** — accurate but O(n), too
   slow for sub-microsecond budget.
2. **Rolling 64-byte window entropy + histogram** — O(1) incremental
   update, fits sub-microsecond target.
3. **Magic-byte delta alone** — fast but misses high-entropy non-header
   encryption (e.g., encrypted content mid-file).
4. **Entropy + magic-byte delta combined** — catches both header
   structure changes and bulk high-entropy encryption.

## Decision

Use a rolling 64-byte Shannon byte-entropy estimate (incremental
histogram + log2 lookup table) combined with a structural magic-byte delta
check. A write is suspect when entropy exceeds 7.5 bits/byte or magic
delta exceeds 4 mismatches.

## Consequences

### Positive
- Sub-microsecond classification cost.
- Detects both header-mangling and bulk-content encryption.
- Verifier-safe: fixed window, bounded histogram, no dynamic allocation.

### Negative
- Rolling window is an approximation; low-entropy encrypted files may
  evade (mitigated by magic-byte delta and BLAKE3 verification in userspace).
- False positives possible on legitimately high-entropy benign data
  (compressed / already-encrypted files); allowlist mitigates.

## Revisit When

False-positive rate on compressed/encrypted benign workloads exceeds
tolerance; add file-type-aware entropy thresholds or a userspace
second-stage classifier.
